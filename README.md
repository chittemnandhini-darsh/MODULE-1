# SDLC BY USING AI

## Project Overview

SDLC by Using AI is a web-based project that demonstrates the Software Development Life Cycle (SDLC) with the support of Artificial Intelligence (AI). It helps users understand the different stages involved in software development, from planning and requirement analysis to design, development, testing, deployment, and maintenance.

## Objectives

* To understand the different phases of SDLC.
* To explore the role of AI in software development.
* To demonstrate how AI can support software planning, coding, and testing.
* To create a simple and user-friendly web interface.

## Technologies Used

* **HTML:** Creates the webpage structure.
* **CSS:** Designs the webpage and improves its appearance.
* **JavaScript:** Adds interactive features.
* **Artificial Intelligence:** Supports software development activities.

## SDLC Phases

1. Planning
2. Requirement Analysis
3. System Design
4. Implementation
5. Testing
6. Deployment
7. Maintenance

## How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click and select **Open with Live Server**.
5. Explore the project in your web browser.

## Benefits

* Improves understanding of SDLC.
* Introduces AI-assisted software development.
* Provides a simple and interactive learning experience.
* Helps students understand software development workflows.

## Conclusion

This project demonstrates the importance of SDLC and explores how AI can support software development. It is useful for students who want to learn about software engineering concepts and modern web technologies.
